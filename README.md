# gofurjon

A modern personal portfolio website built with HTML, CSS and JavaScript.

## Live site

After enabling GitHub Pages in the repository settings, the site will be available at:

https://turgunboyevgofurjon343-arch.github.io/gofurjon/

## Features

- Responsive portfolio layout
- About section
- Project cards
- Skills section
- Contact section
- Simple and lightweight design

## How to run locally

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` — main page structure
- `styles.css` — styling and layout
- `script.js` — small JavaScript for footer year

## Deployment on GitHub Pages

1. Open GitHub repository settings
2. Go to Pages
3. Select `Deploy from a branch`
4. Choose `main` branch and `/root` folder
5. Save

Your portfolio will be published automatically.
